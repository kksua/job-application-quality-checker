# Job Application Quality Checker

A full-stack application that compares a candidate's CV with a job description and provides targeted improvement suggestions.

## Planned features

- Technical skill matching
- Missing skill detection
- Explainable job match score
- Vague and repeated phrase detection
- Relevant experience identification
- Suggested CV bullet improvements
- Weekly application reports

## Technology stack

### Backend

- Python
- FastAPI
- Pydantic
- SQLAlchemy
- pytest
- Ruff
- mypy

### Frontend

- React
- TypeScript
- Vite
- Vitest
- Playwright

### Automation

- GitHub Actions
- Automated tests
- Code coverage checks
