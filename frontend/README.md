# Frontend

React/Vite frontend for the Job Application Quality Checker.

## Run

```bash
npm run dev
```

The app expects the backend at `http://127.0.0.1:8000` by default. Override with:

```bash
VITE_API_BASE_URL=http://127.0.0.1:8000
```

## Checks

```bash
npm run build
npm run lint
npm run test:run
```
